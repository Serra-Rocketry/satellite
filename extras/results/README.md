# Global Simulation Results

This directory contains the final output files from the SRAB aerodynamic simulations.

## Contents

- **Trajectory Maps (`.html`)**: Interactive 3D descent maps.
- **Dashboards (`.png`)**: Performance summaries (LRR - Landing Radius Ratio).
- **Monte Carlo Data (`.csv`)**: Statistical distribution of landing points.
- **Visualization (`.png`)**: 3D trajectory plots and geometry views.

These files are generated by the scripts in `extras/wing-analysis/src/` and represent the final validation for the wing profiles selected for the mission.
