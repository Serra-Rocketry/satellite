\textbf{Risk Assessment Appendix}

Risk is quantified as $R = P \times S$, where $P$ is the failure
probability (1--3) and $S$ the severity (1--3). Failure modes are
organized by mission phase, following the ConOps defined in
Section 2.

\subsection{Mitigations}

\begin{enumerate}
\item \textbf{SRAB deployment failure (Critical):} passive design
  with no hinges; drop tests \#1 and \#2 validated deployment; 4 wings
  provide geometric redundancy — loss of one wing degrades performance
  but does not prevent recovery.
\item \textbf{Battery thermal runaway:} BMS with multiple protections;
  cell cycle testing.
\item \textbf{RBF pin:} RBF circuit in series with the main power
  rail.
\item \textbf{LoRa loss:} local storage (SD) preserves all flight
  data; LoRa is support, not mission.
\item \textbf{SD failure:} automatic LittleFS fallback on internal
  flash.
\item \textbf{Structural break:} ABS 3D-printed, walls $\geq$1.2 mm;
  load analysis.
\item \textbf{Kill switch:} 2 independent kill switches + pre-integration
  verification.
\item \textbf{RF interference:} dedicated team ID protocol; 915 MHz
  channel reservation.
\item \textbf{GPS failure:} LoRa RSSI triangulation as backup; visual
  search.
\item \textbf{Inaccessible landing:} 3 GPS beacons + buzzer for
  localization.
\end{enumerate}

\subsection{Criticality Discussion}

Failure mode \#1 (SRAB deployment) is treated as critical and is the
main driver of the extensive drop-test campaign. Drop tests \#1 and
\#2 demonstrated that passive deployment works consistently without
actuators. The remaining risk is bounded by the LASC regulatory
limits and by the geometric redundancy of the wing arrangement.
